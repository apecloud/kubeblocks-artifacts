# KubeBlocks 小黑风格 10 图选题

来源：kubeblocks.io 官网首页，2026-05-29 抓取。

1. 一个控制台管多种数据库：35+ engines / one operator / unified API。
2. 终结 operator 蔓延：N 个 operator / N 套 CRD / N 套备份升级逻辑，收束成一套 API。
3. 支持现代数据栈：关系型、NoSQL、分析、消息队列、向量/图、时序、对象存储。
4. Day-2 运维：安装之外，还要备份恢复、故障切换、扩缩容、版本升级。
5. 备份与任意时间点恢复：instant backup / PITR / delete protection。
6. 可观测：Prometheus/Grafana、指标日志、慢 SQL、告警规则。
7. 生命周期自动化：创建、扩缩、备份、升级、恢复，控制器持续调谐。
8. GitOps / IaC：统一 YAML、ArgoCD/Flux、声明式数据库拓扑。
9. Addon 低代码接入新引擎：不用写复杂 operator，把 DBA 知识写成配置。
10. 生产案例规模：Sealos 1 人管 6000+ 数据库、VIP 1000+ 集群、快手 10000+ Redis Pods、虎证 IaC。
