# KubeBlocks 单图介绍

## 这张图讲什么

KubeBlocks 像 Kubernetes 上的数据库总控台，把多种数据库的部署、备份、扩缩、故障切换和统一 API 收到一套控制里。

## 适合放在哪里

- KubeBlocks 入门介绍
- 社媒配图
- 讲“为什么需要统一数据库运维平台”的文章

## 图中元素

- 左侧 K8s 工作台：数据库都跑在 Kubernetes 上。
- 多种数据库罐子：MySQL、PostgreSQL、Redis、Kafka、MongoDB、向量服务等。
- 中央 KubeBlocks 控制台：统一控制入口。
- 右侧整齐数据库队列：一套 API 管多种数据服务。
- 机械手：备份、扩缩、故障切换等日常运维动作。

## 改图注意

如果要做正式对外图，可以减少数据库类型数量，避免画面过满；如果面向技术用户，可以保留具体数据库名称。
